# Remix of Fluency Focus Report

Design a report for teacher in LMS application for Language training assessments, where students are given sentences to read and score is evaluated based on the Fluency and Pronunciation. Words that needs Improvements should also listed within the report. Report should have the date filter between which the class performance based on Fluency and Pronunciation is generated. Report should also depict the total students who submitted the assessment and count of students who stand excellent, above average, and need improvement within Fluency and Pronunciation. Common words that were mispronounced and the instances/count to be given against each words. Report should list all the students, excellent performing students(above 75%), Above average students(above 50% but less than 75%) and students who need improvements for the class section and should have option to view the student report. this report should be responsive.
